Community Emergency Information System

A responsive, single-page community information dashboard built with HTML, CSS, and vanilla JavaScript.

Features
- View sample community emergency announcements.
- Add, edit, and delete announcements.
- Store announcement records in browser `localStorage`.
- View sample emergency contacts and evacuation center information.
- Read basic disaster preparedness tips.
- Responsive layout for desktop and mobile screens.

Run in VS Code
1. Extract this project folder.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension.
4. Add a sample announcement, refresh the page, and verify that it remains.

Important safety note
This is a school/demo project. It is not connected to emergency services and does not send real-time alerts. Contact numbers and evacuation centers are fictional placeholders. Do not rely on this demo during an actual emergency. Replace sample information only after confirming it with authorized local officials.

Technology
- HTML
- CSS
- Vanilla JavaScript
- Browser localStorage

No server, database, login, or external API is required.
