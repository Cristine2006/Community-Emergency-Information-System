You are a helpful senior web developer.

WHO:
You are developing a Community Emergency Information System for a local community or barangay.
WHAT:
Create a modern, professional, and responsive Community Emergency Information System using HTML, CSS, and JavaScript in a single HTML file.

FEATURES:
1. Dashboard displaying emergency statistics and important updates.
2. Emergency Announcements where staff can add, edit, and delete announcements.
3. Emergency Hotlines displaying important contact numbers.
4. Safety Information providing emergency preparedness tips.

6. Display announcement titles, descriptions, categories, and dates.
7. Include sample emergency announcements.

- Save announcements using localStorage so data remains after refreshing the page.
- Make all navigation links and buttons functional.
- Allow staff to publish, update, and delete announcements.
- Add confirmation before deleting announcements.
- Display success and error notifications.
- Automatically update dashboard statistics when announcements change.
- Include a search and category filter for announcements.

DESIGN:
- Create a clean, modern, professional dashboard.
- Use dark blue, red, and white as the primary colors.
- Add a sidebar navigation and top navigation bar.
- Use modern cards, icons, shadows, and rounded corners.
- Include responsive layouts for desktop, tablet, and mobile.
- Add smooth hover effects and subtle animations.
- Maintain consistent spacing, typography, and alignment.
- Make the interface user-friendly and easy to navigate.

LIMITS:
- Use only HTML, CSS, and vanilla JavaScript.
- Put all code in one `index.html` file.
- Do not use external libraries, frameworks, or dependencies.
- Use localStorage for data persistence.
- Add short comments to explain important code sections.
- Keep the code organized, readable, and easy to maintain.

OUTPUT:
Provide the complete working HTML code only. Do not include explanations outside the code.
